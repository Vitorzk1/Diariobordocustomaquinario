================================================================================
PLANO E CASOS DE TESTE - REGISTRO DE HORAS DE TRABALHO DAS MÁQUINAS (#1)
================================================================================

[INFORMAÇÕES DA ISSUE]
Título: Registro de horas de trabalho das máquinas #1
Objetivo: Validar o cadastro de máquinas, lançamento diário do horímetro e o cálculo acumulado do tempo de operação.

--------------------------------------------------------------------------------
1. CENÁRIOS DE TESTE DE CASO DE USO E SEQUÊNCIA
--------------------------------------------------------------------------------

ID DO TESTE  : CT-01
NOME        : Cadastro de nova máquina pelo Produtor Rural
CASO DE USO : UC_Cadastrar (Cadastrar Máquina)
PRÉ-COND.   : Usuário autenticado como Produtor Rural.
PASSOS      :
  1. Acessar o menu "Máquinas" no Sistema Agro.
  2. Clicar na opção "Cadastrar Nova Máquina".
  3. Preencher os dados obrigatórios (Nome/Modelo, Código da Máquina, Horímetro Inicial).
  4. Confirmar a operação de cadastro.
RESULTADO   : O sistema persiste os dados da máquina no Banco de Dados e confirma o cadastro com sucesso. A máquina passa a estar disponível para lançamento de horas.

--------------------------------------------------------------------------------

ID DO TESTE  : CT-02
NOME        : Registro diário do horímetro com sucesso (Fluxo Principal)
CASO DE USO : UC_Registrar (Registrar Horas Trabalhadas)
PRÉ-COND.   : Máquina previamente cadastrada no sistema.
PASSOS      :
  1. Selecionar a máquina desejada no formulário de registro.
  2. O sistema busca no Banco de Dados o último horímetro registrado.
  3. Informar o valor do horímetro atual ou as horas trabalhadas no dia (ex: 8 horas).
  4. Confirmar o envio do formulário.
RESULTADO   : O sistema salva a entrada diária, atualiza o somatório de horas no Banco de Dados e exibe a mensagem de confirmação para o operador.

--------------------------------------------------------------------------------

ID DO TESTE  : CT-03
NOME        : Validação e exibição do relatório de horas acumuladas
CASO DE USO : UC_Consultar (Consultar Total de Horas Acumuladas)
PRÉ-COND.   : Registros de horas existentes para a máquina selecionada.
PASSOS      :
  1. Selecionar a máquina para consulta de relatório.
  2. Solicitar o total acumulado do período/geral.
RESULTADO   : O sistema realiza a soma precisa de todos os registros diários gravados no banco e exibe o relatório correto do total de horas acumuladas da máquina.

--------------------------------------------------------------------------------

ID DO TESTE  : CT-04
NOME        : Validação de entradas inválidas no registro de horímetro (Fluxo de Exceção)
CASO DE USO : UC_Registrar (Registrar Horas Trabalhadas)
PRÉ-COND.   : Formulário de registro de horímetro aberto.
PASSOS      :
  1. Selecionar uma máquina cadastrada.
  2. Tentar inserir um valor de horas negativo (ex: -5 horas) ou caracteres alfabéticos.
  3. Tentar salvar a operação.
RESULTADO   : O sistema impede o envio ao Banco de Dados, exibe uma mensagem de validação ("Valor de horímetro inválido") e mantém a integridade dos dados anteriores.
