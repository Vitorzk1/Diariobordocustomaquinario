# Diariobordocustomaquinario
O desenvolvimento de um sistema para controlar o uso e os custos de máquinas agrícolas, registrando horas de trabalho, consumo de combustível e manutenções preventivas. A solução busca substituir métodos manuais, reduzindo erros, desperdícios e falhas, além de melhorar a eficiência operacional.

Projeto desenvolvido pelos alunos do 3B de Informática do IFRO Campus Ariquemes. (2026)
